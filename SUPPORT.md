# SEER Support

Need help with SEER? Use one of the options below.

## 1) Report a bug or request a feature

Open a GitHub issue:

- https://github.com/Cole-Cant-Code/Ollama-Cloud-App/issues

When possible, include:

- Device model and iOS version
- App version
- Steps to reproduce
- Screenshots or screen recording
- Relevant logs (without secrets)

## 2) Security and sensitive issues

Do not post API keys, tokens, or personal data in public issues.

For sensitive security concerns, open a private GitHub security advisory:

- https://github.com/Cole-Cant-Code/Ollama-Cloud-App/security/advisories/new

## 3) General troubleshooting

- Confirm your API key is valid and active
- Confirm network connectivity
- Restart the app and retry
- Update to the latest app version

## Response time

Support is best-effort. We review new issues regularly and prioritize reproducible bugs.
