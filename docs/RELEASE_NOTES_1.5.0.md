# SEER 1.5.0 — App Store "What's New"

Paste into App Store Connect → SEER → version 1.5 → "What's New in This Version".
Covers everything since 1.0.1 (the last version approved for the App Store).

---

SEER 1.5 is our biggest update yet.

NEW
• Projects & Code Workspace — create a project, let SEER create and edit files with a built-in file tree and code editor, and export it all as a zip
• GitHub attachments — connect with a GitHub token and attach repository files as chat context
• Reasoning Scaffolds — build reusable reasoning templates (role, steps, tone) and attach them to any chat
• Visualizations — SEER can render interactive charts, tables, timelines, and dashboards (toggle in Settings)
• Message branching — edit a prompt or regenerate a reply, then flip between versions
• Voice dictation, conversation search, and chat export/share as Markdown

IMPROVED
• Clearer error messages when a model or server fails mid-response
• A notice when a reply hits the output token limit
• OpenAI models now work consistently wherever you pick a model
• Dozens of reliability fixes across chats, projects, and attachments

Your chats stay on your device. Manage data sharing anytime in Settings.
